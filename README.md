Diario Deportivo

Este proyecto es una portada digital de un diario deportivo creada con **HTML y CSS**, aplicando los principios de **diseño responsivo** y **Mobile First**.

#Descripción
El sitio presenta una estructura típica de un periódico online, con:
- Una **noticia principal** con imagen destacada.
- **Noticias secundarias** organizadas en una columna lateral.
- Una **sección de publicidad** con imagen y texto.
- Un **menú de navegación** funcional.
- Diseño adaptable a distintos tamaños de pantalla usando **Flexbox**.
